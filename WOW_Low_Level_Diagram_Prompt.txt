Show the internal relationships clearly:

- Feature hooks call the typed RPC client.

- The Hono API routes requests to the correct feature handler.
- Session middleware loads the authenticated user.
- Authorization checks verify workspace membership and roles.
- Validation schemas verify payload shape and required fields.
- Server handlers read and write Appwrite documents.
- Appwrite returns documents and session/user data.
- React Query caches and refreshes data after mutations.
- Route changes update visible screens and panel state.
